# Stock Portfolio Tracker - CodeAlpha Internship Task 2

: Description
This is a Python project for CodeAlpha Internship. It tracks stock portfolio value based on user input.

: Features
- Predefined stock prices (AAPL, TSLA, GOOGL, MSFT, AMZN)
- User can add stock quantity
- Calculates total portfolio value
- Simple and beginner-friendly

: How to Run
1. Run the file: `python stock_portfolio.py`
2. Enter stock symbol like AAPL, TSLA
3. Enter quantity
4. Type `done` to see total value

 : Example
- AAPL: 10 x $180 = $1800
- TSLA: 5 x $250 = $1250
- Total: $3050
